## [Unreleased]

### Added

- Formula for `animoria` — unused and duplicate visual asset discovery suite
- Formula for `debuggatha` — repo-aware code reviewer for AI coding agents
- Formula for `obfusku` — installs the Obfusku CLI and Language Server (`obfusku-lsp`) together
- Formula for `obfusku-lsp` — standalone Language Server Protocol server for editor integrations
- Formula for `tensorsuggestlite-cli`
- Formula for `somnia-cli`
- Formula for `orph-cli`
- Formula for `lacuna-cli`
- Formula for `psychoquine-cli`
- `CLAUDE.md` and `.github/FUNDING.yml` standard templates
- `.gitignore` to exclude macOS artifacts, Ruby gems, and Homebrew internals

### Changed

- Updated GitHub Actions dependencies across workflows to latest versions and pins
- Aligned community documents (`SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `.github/PULL_REQUEST_TEMPLATE.md`) with Sxnnyside Ecosystem OSS Bundle v2
- Moved `CODEOWNERS` to `.github/CODEOWNERS` (standard GitHub location)
- Updated README to document all distributed formulas
